# My Awesome Resume

This is a Next.js application that serves as my personal resume.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

You can easily customize the content of the resume by editing the `data/resume.json` file. The page will automatically update to reflect the changes.
